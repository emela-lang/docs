このページの Emela は、ブラウザの中だけで動きます。コンパイラを WebAssembly にしたものがコードを JavaScript に変え、その JavaScript を `emela run` と同じランタイムで動かします。サーバーには何も送りません。

<Playground />

ドキュメントの中の例のうち、`main` のある例には「▶ Run」が付きます。押すと、このページと同じ仕組みで実行して結果を表示します。

## ブラウザで使えないもの

`with Platform` は書けますが、次の操作はブラウザでは働きません。手元に[インストール](/start/installation/)して `emela run` で試してください。

| 操作 | ブラウザでの結果 |
|---|---|
| `FileSystem` | 読み書きは `FileSystemFailure` で失敗し、`exists` と `is_directory` は `False` を返す |
| `Env` | 呼ぶと止まる |
| `Stdin`、`Args` | 入力も引数もない |
| `Http` のサーバー | 動かない |

10 秒たっても終わらないプログラムは止めます。
