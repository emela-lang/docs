言語の全体を順に見るページは、[Emela ツアー](/tour/) に移りました。1ページに1つの機能を取り上げ、どのページのプログラムもブラウザの中でその場で書き換えて動かせます。インストールは要りません。

ツアーは6章です。

1. [基本](/tour/basics/values/): 値、束縛、関数、パイプ、再帰
2. [データ](/tour/data/types/): type、enum、match、List、Option
3. [エラー](/tour/errors/fail/): fail、fails、escape
4. [エフェクト](/tour/effects/handlers/): effect と handler、エフェクトの別名と uses、State、ハンドラの差し替え
5. [並行処理](/tour/concurrency/sleep/): 待つ操作、タスク、race と timeout、Task.Group
6. [その先へ](/tour/more/modules/): モジュール、Trait、次に読むもの

手元で動かすときは [インストール](/start/installation/) と [最初のプロジェクト](/start/first-project/) を、ほかの言語の書き方との対応は [他の言語との対応](/start/coming-from/) を読んでください。
