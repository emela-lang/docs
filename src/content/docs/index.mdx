Emela は、小さなコア・明示的な実行時挙動・型付きの effect 追跡を軸にした、
実験的な関数型言語です。関数が要求する **capability（能力）** を型に書き、
その集合がそのまま WebAssembly サンドボックスの **権限表** になります。

```emela
import std.io

fn main() -> Unit uses { Io } {
    Io.print("Hello, World!\n")
}
```

<CardGrid>
	<Card title="capability を型で追跡" icon="approve-check">
		副作用は関数型の `uses` 節に書きます。宣言なき副作用は型エラー、
		import されないホスト関数はサンドボックスが実行時にも拒否します。
	</Card>
	<Card title="null が無い" icon="error">
		値の不在は `Option<T>` で表します。所有権・借用・move も導入せず、
		メモリはランタイムが管理します。
	</Card>
	<Card title="式指向・不変" icon="pencil">
		束縛は不変、反復は再帰。`if` / `match` / block はすべて式で、
		`return` はありません。
	</Card>
	<Card title="移植可能な意味論" icon="rocket">
		`Int` は i32、`Float` は f64 に固定。演算の観測可能な意味は
		全 backend で一致します。
	</Card>
</CardGrid>
