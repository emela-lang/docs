Emela は、データの定義、それを操作する関数、副作用の明示の3つを単純に保つことを基準にした関数型言語です。関数が起こしうるエラー（`fails`）と使うエフェクト（`use`）は型の一部で、書かなければコンパイラが推論します。

```emela check
import Std.Console.{Console}
import Std.Platform.{Platform}

error Negative(n: Int)

fn half(n: Int) -> Int fails Negative {
  if n < 0 { fail Negative(n:) }
  n / 2
}

fn main() {
  with Platform {
    console = use Console
    [10, -4, 7]
      |> List.map(fn(n) { Int.to_string(half(n)) escape { Negative(n:) -> "#{n} は負" } })
      |> String.join(", ")
      |> console.print_line
  }
}
```

```console
$ emela run main.emel
5, -4 は負, 3
```

<CardGrid>
	<Card title="エラーは型に載る" icon="error">
		`fail` で失敗し、`escape` で受けたいエラーだけを値に戻します。
		受けなかったエラーは呼び出し元へ伝わり、その集合が関数の型に残ります。
		Result 型も try / catch もありません。
	</Card>
	<Card title="副作用はエフェクトで" icon="setting">
		`effect` で操作を宣言し、`handler` で実装し、`with` で供給します。
		テストではハンドラを差し替えるだけで済み、モックは要りません。
	</Card>
	<Card title="await のない並行処理" icon="random">
		fiber はスコープの中でだけ起動し、スコープより長生きしません。
		中断する操作も普通の呼び出しと同じ形で書きます。
	</Card>
	<Card title="同じ結果を、どのターゲットでも" icon="rocket">
		出力先は JavaScript、WebAssembly、C。`Int` は32ビット、`Float` は
		IEEE 754 の64ビットに固定し、どのターゲットでも同じ結果を返します。
	</Card>
</CardGrid>
