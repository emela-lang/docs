`half` は `Negative` で失敗しうると型に書いてあります。`main` はそのエラーを `escape` で受けて文字列に戻し、出力します。`main` の `Console` は `with Platform` が供給します。

```emela check
import Std.Console.{Console}
import Std.Platform.{Platform}

error Negative(n: Int)

fn half(n: Int) -> Int fails Negative {
  if n < 0 { fail Negative(n:) }
  n / 2
}

fn main() {
  with Platform {
    console <- Console
    [10, -4, 7]
      |> List.map(|n| Int.to_string(half(n)) escape { Negative(n:) -> "#{n} は負" })
      |> String.join(", ")
      |> console.print_line
  }
}
```

```console
$ emela run main.emel
5, -4 は負, 3
```

	<Card title="エラーは型に載る" icon="error">

	</Card>
	<Card title="副作用はエフェクトで" icon="setting">
		実装は `with` でハンドラを渡して決まります。テストではハンドラを差し替えます。
	</Card>
	<Card title="await のない並行処理" icon="random">
		タスクは `with` の項目の中でだけ動き、それを始めた `with` より長生きしません。
	</Card>
	<Card title="どのターゲットでも同じ結果" icon="rocket">
		JavaScript、WebAssembly、ネイティブの実行ファイルに出力します。`Int` は32ビットに固定です。
	</Card>
</CardGrid>
