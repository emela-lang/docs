`half` は `Negative` で失敗しうると型に書いてあります。`main` はそのエラーを `escape` で受けて文字列に戻し、出力します。`main` の `Console` は `with Platform` が供給します。

```emela check
import Std.Console.{Console}
import Std.Platform.{Platform}

error Negative(n: Int)

fn half(n: Int) -> Int fails Negative {
  if n < 0 { fail Negative(n:) }
  n / 2
}

fn main() {
  with Platform {
    console = use Console
    [10, -4, 7]
      |> List.map(fn(n) { Int.to_string(half(n)) escape { Negative(n:) -> "#{n} は負" } })
      |> String.join(", ")
      |> console.print_line
  }
}
```

```console
$ emela run main.emel
5, -4 は負, 3
```
