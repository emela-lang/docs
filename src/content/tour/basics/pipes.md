title: 無名関数とパイプ
description: "|x| 式 で書く無名関数と、|> で処理をつなぐパイプ"

---

名前の要らない関数は `|引数| 式` と書きます。`|n| n * n` は、受け取った `n` の2乗を返す関数です。引数がなければ `|| 式`、本体が長ければ `|n| { ... }` と書きます。

`x |> f(a)` は `f(x, a)` と同じ意味で、左の値が右の関数の最初の引数に入ります。データを左から右へ流すように書けるので、処理の順に読めます。

右のプログラムは、1 から 10 のうち偶数だけを選んで2乗し、合計します。

- `List.range(1, 11)` は 1 から 10 までのリスト（11 は含まない）
- `List.filter` は条件を満たす要素だけを残す
- `List.map` は要素ごとに関数を適用する
- `List.fold` は初期値から始めて、要素を1つずつ畳み込む

`for` や `while` はありません。繰り返しはこうしたリストの関数か、次のページで見る再帰で書きます。

> **試してみよう**
> `|> List.filter(...)` の行を消すと合計はいくつになるでしょうか。

```emela check tour
fn main() {
  total = List.range(1, 11)
    |> List.filter(|n| n % 2 == 0)
    |> List.map(|n| n * n)
    |> List.fold(0, |sum, n| sum + n)
  dbg(total)
  ()
}
```

```console
$ emela run main.emel
220
```
