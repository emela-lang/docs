title: 値と dbg
description: 整数、小数、文字列、真偽値、リストと、値を覗く dbg

---

`dbg(x)` は、値 `x` をそのまま表示して `x` を返します。`Console` と違って `with` が要らないので、値を手早く覗くのに使います。このツアーでも以降はよく使います。

右のプログラムは基本の値を並べています。

- `Int` は整数、`Float` は小数。`1` と `1.0` は別の型で、混ぜて計算するには変換が要る
- `String` は文字列。`#{...}` で値を埋め込む
- `Bool` は `True` と `False`
- `List[Int]` は整数のリスト。`[1, 2, 3]` と書く
- `(1, "a")` はタプル。違う型の値を組にする

`dbg` が出すのは、値をプログラムに書くときの形です。文字列は引用符付きで出ます。

`main` の最後の `()` は「何もない値」で、`main` は値を返さないことを表します。`dbg(...)` で終えると、`main` が値を捨てているという警告が出ます。

> **試してみよう**
> `1 + 1.0` と書いて、どんなエラーになるか見てください。

```emela check tour
fn main() {
  dbg(1 + 2 * 3)
  dbg(7 / 2)
  dbg(7.0 / 2.0)
  dbg("Emela" == "Emela")
  dbg("1 + 1 = #{1 + 1}")
  dbg([1, 2, 3])
  dbg((1, "a"))
  ()
}
```

```console
$ emela run main.emel
7
3
3.5
True
"1 + 1 = 2"
[1, 2, 3]
(1, "a")
```
